この資料の読み方

全カードランキングではなく、確認できた重要77枚の判断資料です。添付の9月13日版（85枚選抜）を基礎に、新たに確認した黒の除去・低優先札などを追加してドラフト用に再構成しました。公式ギャラリーの全件データは取得・照合できていません。未掲載＝弱い、ではありません。

「序盤・中盤・終盤」はピックの進行を指します。本文の優先順位・構築目安は本資料の考察です。実測の勝率、平均ピック順、卓で一周する確率を示すものではありません。英語名を基準にし、未確認の日本語名を創作していません。

根拠はカード欄で「添付資料から継承」「今回本文を確認」に分けています。継承カード全件を最新Oracleで再照合した版ではありません。FRAの通常ドラフトを対象とし、FRCとピック２・ドラフトは対象外。SPGの個別評価も今回は対象外です。

01　迷ったときの優先順

序盤は「単体で働く」。中盤は「勝ち筋につながる」。終盤は「欠けた役割を埋める」。

02　ピックの３段階

段階目的取るもの避ける行動
序盤：P1P1〜P1P5強い出発点と色の余地を残す自立したボム → 汎用除去・上位生物 → 柔軟な混成／無色。僅差なら単色を評価初手の金色札に縛られる。支援ゼロの低性能な専用札から始める
中盤：P1P6〜P2終了主色と勝ち筋を絞る複数巡続く良質札、２マナ域、報酬に足りない支援、同色の金色札１枚流れただけで空いていると断定。P2の逆方向だけでP1の観測を捨てる
終盤：P3全体40枚の穴を埋める不足している軽量生物・広い除去・色土地・勝ち手段。完成後はサイド他色ボム１枚で総入れ替え。既に過密な大型を点数だけで追加

遅い巡目は別の軸

P1P10はドラフト全体ではまだ中盤でも、そのパックでは遅い巡目です。ここで使える主色札が続くならシグナル候補。ただし金色の専用札１枚は根拠が弱い。

撤退は追加投資で判断

初手を使いたい気持ちより、これから取れる23枚を見る。P1後半で第２色が乏しく、別色の優良札が続けば副色変更。P3では少数差し替えで成立する場合だけ検討。

一周を当てにしない

汎用除去と軽量戦力は必要なら今取る。専用支援は戻る可能性があるが保証はない。片割れの封入構造もあるため、伝説１枚の残り方だけで卓の色を断定しない。根拠

03　各色の作り方

白｜除去から、飛行か回復へ

Memory Trapを基準に開始。青と組むなら軽量飛行と盤面の横幅、緑と組むなら通常の戦力でもある回復源を取る。中盤ではThaliaやVanguardが複数の役割を兼ねる。

回復だけ、トリックだけにしない。Loyal Tutorは探す実物のPWがなければ採用理由がない。

青｜盤面を置いてから資源を回す

Infinite Courseworkで危険物に触れ、Proftなどの利益を盤面で守る。Foreseerは４マナ域の柱、Chronologistは序盤から終盤へつながる。

Protege’s Awakeningを高得点だけで集めない。４ターン目に防御できない手札なら、先に生物を補う。

黒｜除去を入口に２つの方向へ

広いExtended Absenceと軽いLast Gaspを揃え、青との墓地か赤とのダメージへ。黒Danithaは対象を取る除去と自然につながる。

黒Proftは墓地７枚まで唱えられない。見た目の３マナ域としてマナカーブを埋めない。黒が薄いという旧資料の選抜偏りを引き継がない。

赤｜火力＋実際に攻撃する戦力

No Admittanceから入り、Tetsukoなら非クリーチャー呪文、Master of Barbsなら反復ダメージ、緑相方なら大型と加速を揃える。

１点を与えるだけの札で低マナ域を埋めない。ダメージの報酬か、相手を削り切る打点が必要。

緑｜中型・加速・終着点をつなぐ

Propagator、接死の２マナ、３マナ3/3で土台を作り、Ghaltaなどへ。緑白は回復を、赤緑は魂木を勝ち手段につなげる。

大型が揃った後は加速と序盤を取る。GGGGや10マナの上限を、そのまま使いやすさに換算しない。

混成・無色・土地｜色の余地も資産

ChronologistやVanguardは片方の色だけで使える。Keeperは色変更しても残る。同色２色土地は採用予定札が揃った後、控え候補の呪文より優先できる。

WUの魔除けと(W/U)の生物は違う。魂木は赤・緑しか出ず、白・青・黒へのタッチ基盤にはならない。

04　重要77枚：検索できるピック表

S＝自立性の高いボム候補、A＝上位、B+/B＝有力な通常戦力、C+＝役割で採用。条件は弱さの意味ではなく構成依存、低優先は通常構築で急いで取らない札、サイドは対戦相手依存です。

中盤・終盤の「優先」は、その色が自分の主色として成立している場合。点数順の絶対序列ではありません。色フィルターはその色を含むカードを表示し、混成と金色はコスト欄で区別します。

シナジーの目安：反復できる支援２〜３枚が見えていれば報酬を上げる出発点になります。ただしこれは経験則で、達成保証ではありません。１枚の反復エンジンへの依存、マナ消費、除去されるリスクも考慮。単発回復３枚と継続回復３枚を同じに数えないでください。

06　「取らなくてよい」の４種類

区分例どう扱うか
通常は低出力Loyal Tutor、支援なしCruel Calculations、通常構築の９マナ蘇生優良C/Uより先に取らない。デッキに入らないならメイン候補を優先
専用構築で化けるParadox Shaper、Voxmancer、Ajani Resolute支援と報酬を確認して評価を上げる。単純な弱いカード一覧に混ぜない
サイド向けRefute Destiny、Precise Redaction、Terminal CriticismBO3では終盤に確保。BO1では必要なメイン札・土地を優先
強いが唱えにくいHexhaven Invigorator、金色スフィンクス、Emrakulカードパワーとマナ基盤を分離。自分の構成で使えないなら流す
重複が弱い／役割が飽和２枚目以降の重い補充、同名伝説、大型の過剰１枚目と同じ評価にしない。伝説２枚目も常に不要ではなく、代替・除去耐性として比較

「ピックしない」は早い巡目で競争しないという意味です。他に使える札がないなら確保して構いません。自分のデッキを改善できる札を取れるのに、相手への妨害だけを目的としたカットへ逃げないこと。

07　条件を置いて、実際に選ぶ

以下は比較用の仮想状況です。同じパックへの封入や出現頻度を確認した例ではありません。

P1P1｜Memory Trap と Loyal Tutor

所持状況：強いPWをまだ１枚も持っていない。

この条件の選択：Memory Trap。対象のないサーチに投資せず、広い除去で開始。

逆転条件：既に強いPWがある中盤以降でも、除去不足ならTrapを維持。Tutorは完成度の高いデッキでのみ比較。

P1P4｜No Admittance と Stingerquill Charm

所持状況：赤の良札２枚、黒は未確定。

この条件の選択：No Admittance。僅差の柔軟性を買い、相方を赤緑・青赤などへ残す。

逆転条件：黒にも強い札があり黒赤が有力なら、インスタントと各モードを使えるCharmが上がる。

P1P8｜青の良札が続いた

所持状況：初手は緑ボム。その後は緑が薄く、Infinite Courseworkと青の良い生物が複数巡流れてきた。

この条件の選択：青を主色候補に上げる。緑ボムを捨てる必要はまだなく、青緑や青＋別色を比較。

逆転条件：今回１枚だけ青が残ったなら断定しない。送られてくる数巡を観測。

P2P3｜Semester Foreseer と Protege’s Awakening

所持状況：青主色。軽量の守りが薄く、４マナ補充を既に１枚所持。

この条件の選択：Foreseer。盤面に3/4を置くことを優先。

逆転条件：地上を十分止められ、勝ち手段もあり、継続資源だけ不足ならAwakeningを比較。

P2P5｜Titanbones と Greenhouse Propagator

所持状況：緑白。Titanbonesを１枚持つが回復源は少ない。

この条件の選択：Propagator。既存の報酬を動かし、マナも伸ばす。

逆転条件：回復源が十分で４マナの勝ち手段が少ないならTitanbones。伝説重複の扱いも確認。

P2P7｜Paradox Shaper と Void Extrapolator

所持状況：青黒。墓地報酬はあるが、２ターン目に普通に戦える生物が少ない。

この条件の選択：まずVoid Extrapolatorを優先する案。戦闘力のある２マナ域で事故を減らす。

逆転条件：防御が既に足りており、墓地７枚への到達手段だけが不足ならShaperが逆転。

P3P2｜Ghalta と Arcane Amphisbaena

所持状況：緑主色。大型３枚、序盤の生物が足りない。

この条件の選択：Amphisbaena。追加の上限より２ターン目の防御。

逆転条件：２マナ域が足りていて大型が１枚もないならGhalta。

P3P5｜主色２色土地 と 追加の４マナ域

所持状況：白青。使いたい呪文は23枚以上あり、色拘束が重い。

この条件の選択：必要な２色土地。控えの呪文より実際の初手・展開を改善する。

逆転条件：速い構築でタップインが過剰、または４マナの主力が足りないなら再比較。

P3P1｜他色のボム

所持状況：赤白の骨格があり、黒源も黒のプレイアブルもない。黒黒のボムを開いた。

この条件の選択：既存の赤白を改善する札を取る。ボムの単体性能とデッキへの貢献は別。

逆転条件：黒の良札を十分保留し、少数差し替えで主色変更できる場合だけ構築全体を比較。

P3後半｜色限定対策 と メイン23枚目

所持状況：青のBO3。Precise Redactionと、まだ不足している２マナ生物の比較。

この条件の選択：２マナ生物。まずゲーム１で成立する40枚を作る。

逆転条件：メインが完成済みなら、相手次第で強い対策札を確保。

08　各パック終了時と、40枚の点検

時点点検すること修正の方向
P1終了主色候補、使える枚数、流れてきた色、２〜３マナ域採用候補７〜９枚は一つの目安。届かなくても失敗と決めず、固執している色を点検
P2終了主色２色、勝ち筋、軽量域、広い除去、支援と報酬採用候補15〜18枚程度から、P3で埋める役割を３つに絞る。枚数だけでなく機能を数える
P3終了実際の23枚、色源、条件未達の札、サイド強い順に23枚を選ばず、唱えられない／守れない／勝てない穴を解消
40枚の出発点土地17＋呪文23。生物14〜17枚程度を目安トークン生成と準備の戦力は別記。準備呪文を独立カードとして二重計上しない
低マナと除去２マナ以下の盤面札５〜７、干渉４〜６を検討経験則。除去とバウンス・トリックを区別し、墓地条件の黒Proftは序盤戦力に含めない
上のマナ域加速なしでは６マナ以上を絞る。まず０〜２枚から点検速攻型ならさらに少なく、魂木型なら増やせる。大きい札の枚数より唱えるまでの手順を見る

マナ基盤

２色の９／８配分は出発点にすぎません。早いターンのダブルシンボル、タップイン、準備呪文の支払い先まで確認。重いシングルシンボルのタッチなら３源程度を検討の出発点にできますが、これも保証ではありません。序盤から必要な札やダブルシンボルはタッチ向きではありません。

魂木は赤・緑の継続加速。白・青・黒を出す土地の代わりには数えません。マナ・クリーチャーも除去され、唱えるための最初の色源が必要です。

ゲームの序盤・中盤・終盤

序盤：盤面を作り、自分のジェイスを守る／相手のジェイスへ攻撃できる形にする。
中盤：展開・除去・準備呪文の追加コストを配分。利益だけ取って盤面を失わない。
終盤：飛行・トランプル・反復ダメージで決着。切削を使う場合は残りライブラリーも数える。

資源生成が豊富でも、環境全体が低速だと確認したわけではありません。

  1. 黒の参入基準を追加。Extended AbsenceとLast Gaspを確認し、黒も汎用除去から入る色として整理。旧資料に黒コモンが少なかったことを色の弱さへ換算しない。
